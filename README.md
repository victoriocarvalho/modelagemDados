# Curso Básico de Modelagem de Dados

Este repositório reúne os materiais de um curso básico de modelagem de dados. O curso aborda as três etapas do projeto e da implementação de bancos de dados:

- **Modelagem conceitual**, com a identificação dos conceitos de um domínio e das relações entre eles;
- **Modelagem lógica**, com a transformação do modelo conceitual para o modelo relacional, usando tabelas, colunas e chaves;
- **Modelagem física**, com a geração do código SQL e a criação do banco de dados.

O conteúdo utiliza uma abordagem orientada a **dinâmicas práticas**. Em cada dinâmica, os conceitos são estudados e aplicados nas etapas conceitual, lógica e física, permitindo acompanhar sua transformação até a implementação de um banco de dados.

Para começar, consulte o [índice do curso](indice.md).
